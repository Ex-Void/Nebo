# «Небо» — сайт прогноза погоды

Сайт на **HTML, CSS и JavaScript**, сервер — **Node.js**. Сторонние пакеты не нужны: база данных — встроенный в Node.js модуль SQLite (`node:sqlite`), поэтому `npm install` выполнять не требуется.

## Запуск

1. Установите **Node.js 22.13 или новее** (LTS-версия с https://nodejs.org/).
2. Откройте папку проекта и запустите одним из способов:
   - дважды щёлкните **`run.bat`** (Windows);
3. Браузер откроется сам: http://127.0.0.1:3000

Остановить сервер — `Ctrl+C` или закрыть окно консоли.

## Главный администратор

Логин и пароль главного администратора задаются в файле **`config.js`**:

После изменения перезапустите сервер. Там же задаётся пароль полной очистки базы (`WIPE_PASSWORD: 'STOP'`) и порт.

Права:

| Действие | Главный | Остальные администраторы |
|---|---|---|
| Города, текущая погода, сообщения, журнал | ✓ | ✓ |
| Создавать и удалять администраторов | ✓ | — |
| Полная очистка базы данных | ✓ | — |
| Смена своего пароля на сайте | — (только в `config.js`) | ✓ |

Администраторы не могут удалять друг друга — удалить администратора может только главный.

## Вкладки сайта

- **Сейчас** — текущая погода выбранного города и ближайшие 5 дней.
- **Прогноз** — прогноз на 7 дней и интерактивный график.
- **Обратная связь** — форма, сообщения сохраняются в базу. Тексты вступления и блока «О проекте» вписываются в `public/feedback.html`.
- **Админ** — панель администратора: Города, Текущая погода, Сообщения, База данных, Администраторы, Журнал.

## База данных

Файл `data/nebo.db` создаётся при первом запуске и заполняется демо-данными (9 городов, прогноз на 7 дней).
В разделе «База данных» панели администратора описано, что хранится в каждой таблице, и есть полная очистка базы (по паролю из `config.js`).
Чтобы вернуть сайт к исходным демо-данным, остановите сервер и удалите папку `data`.

Кнопка «Обновить из интернета» (разделы «Города» и «Текущая погода») загружает реальную погоду из бесплатного API Open-Meteo. Без интернета сайт работает на данных из базы.

## Структура проекта

```
server.js        — сервер Node.js: раздача страниц, API, вход, права администраторов
db.js            — база данных SQLite: таблицы, демо-данные, очистка
weather.js       — загрузка погоды из Open-Meteo
config.js        — логин/пароль главного администратора, пароль очистки, порт
package.json     — описание проекта и команда npm start
run.bat          — запуск в Windows
public/          — сайт: index.html, forecast.html, feedback.html, admin.html, 404.html
public/css/      — стили и CSS-анимации
public/js/       — common.js (общее), icons.js (иконки), sky.js (небо), chart.js (график),
                   now.js, forecast.js, feedback.js, admin.js (страницы)
data/nebo.db     — файл базы данных (создаётся автоматически)
```
